# Как создать отдельную сессию помощника

Это будет **новый вход в тот же Telegram-аккаунт**, со своим ключом и записью в списке устройств. Переписки аккаунта общие для всех его устройств. Создавать второй аккаунт и получать собственные API ID/Hash не нужно.

## 1. Подготовьте программу

Распакуйте архив в отдельную папку. Нужен Python 3.10 или новее.

- **Windows:** откройте `start.bat`.
- **Mac:** откройте `start.command`; если двойной щелчок не запускает его, в Terminal из этой папки выполните `bash start.command`.
- **Linux:** создайте `.venv` через `python3 -m venv .venv`, установите зависимости командой `.venv/bin/python -m pip install -r requirements.txt`, выполните `.venv/bin/python -m assistant setup`, затем `.venv/bin/python -m assistant run`. Скрипт `start.command` включает службу macOS и для Linux не подходит.

При первом запуске установятся зависимости. Программа попросит токен вашего бота от [@BotFather](https://t.me/BotFather). Если бот уже создан, используйте его существующий токен. Ввод скрыт, вставьте токен и нажмите Enter.

Затем появится выбор способа входа.

## 2А. Через QR, если Telegram/AyuGram есть на телефоне

1. Выберите **1** в терминале.
2. Откроется локальная страница с QR-кодом. Этот код относится к новой сессии помощника.
3. На телефоне в нужном аккаунте откройте **Настройки → Устройства → Подключить устройство**. Название кнопки может немного отличаться в вашем клиенте.
4. Отсканируйте QR-код с экрана компьютера и подтвердите вход.
5. Если программа попросит пароль двухэтапной защиты, введите его в терминале.

QR обновляется автоматически. Сайт `my.telegram.org` для этого не используется. Механизм подтверждения описан в [документации Telegram](https://core.telegram.org/api/qr-login).

Если AyuGram установлен только на компьютере и в нём нет сканера, используйте вариант 2Б.

## 2Б. Из tdata AyuGram Desktop без телефона

1. Найдите **свою авторизованную папку `tdata`**. В портативной сборке она обычно находится рядом с `AyuGram.exe`. Для установленной Windows-сборки проверьте `%APPDATA%\AyuGram Desktop\tdata` через Win+R. Если путь отличается, посмотрите строку `Working dir` в файле `log.txt` AyuGram: `tdata` находится внутри рабочего каталога. [Пример рабочего каталога в репозитории AyuGram](https://github.com/AyuGram/AyuGramDesktop/issues/319).
2. **Полностью закройте AyuGram Desktop**, в том числе через значок в системном трее. Не выходите из самого аккаунта: его вход должен оставаться сохранённым в `tdata`.
3. В программе помощника выберите **2** и укажите полный путь к самой папке `tdata`.
4. Если у AyuGram установлен локальный код-пароль блокировки приложения, введите его. Если кода нет, нажмите Enter. Это **не** облачный пароль двухэтапной защиты.
5. Если в папке несколько аккаунтов, выберите нужный по его Telegram ID.
6. Если Telegram запросит облачный пароль двухэтапной защиты, введите его в терминале.
7. Дождитесь сообщения **«Создан отдельный ключ входа»** и успешного завершения настройки. После этого AyuGram можно снова открыть.

Помощник читает исходный ключ в память только для подтверждения нового входа. Он не сохраняет этот ключ в свою `.session`, не перезаписывает `tdata` и проверяет, что новый ключ отличается от исходного. Это отличается от постоянного использования копии сессии AyuGram.

Если вы меняли API-профиль AyuGram, запустите настройку вручную, указав его. Например:

```bash
python -m assistant setup --login tdata --source-api android
```

Для нестандартной сборки, другого формата данных или неизвестного профиля используйте вход по QR. Совместимость с каждой версией AyuGram не гарантируется.

## 3. Проверьте новый вход

Откройте AyuGram/Telegram → **Настройки → Устройства**. Должен появиться дополнительный вход с моделью устройства **Personal Telegram Assistant**. Название приложения Telegram может отображать как Telegram Desktop — ориентируйтесь также на модель устройства, время и место нового входа.

Файл помощника: `data/assistant-user.session`. Это собственная сессия, отличная от сессии AyuGram. Повторный обычный запуск использует её и не создаёт ещё одно устройство каждый раз.

Чтобы отозвать доступ помощника, завершите **именно этот вход** в списке устройств. Сессию AyuGram завершать не требуется. Если понадобилась ещё одна совершенно новая сессия помощника, остановите программу и задайте в `.env` другой `DATA_DIR`, например `data-second`, затем повторите setup. Это создаст также отдельную очередь и настройки.

## 4. Запустите работу бота

`start.bat` и `start.command` после успешного входа запускают бота автоматически. При ручной настройке выполните:

```bash
python -m assistant run
```

Откройте своего бота в Telegram, нажмите **Start → ⚙️ Настройка → Старый режим** или **Новый режим**, выберите первое сообщение (текст или стикер) и задайте ГС1 и ГС3 (прежнее ГС2). Для нового режима отдельно задайте ГС2 для отправки подряд с ГС1. После этого можно передать username тестового контакта.

Токен, пароли, QR-код, `.session` и `tdata` остаются у вас локально. В архиве проекта и репозитории GitHub их нет. Для нового входа потребуется ваше подтверждение в Telegram или через собственную авторизованную tdata.
